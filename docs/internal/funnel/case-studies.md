# TASK-FUNNEL-002 - Tiered Case Studies

**Repo-verifiable state:** case-study structure ready; client-anonymized examples require operator review.

## Public Case Study Tiers

| Tier | Source | Publication rule |
|---|---|---|
| CyberSkill self-audit summary | Existing example audit | Publicly capped at L3 without third-party verification. |
| Anonymous client audit | Paid/private work | Publish only with written client approval or fully anonymized composite. |
| Marquee OSS audit | TASK-AUDIT-001 | Publish only after maintainers approve the public audit. |

## Template

1. Context: system size, team shape, scope, and evidence available.
2. Baseline: DSAF-25 score, public cap, and confidence.
3. Three highest-leverage gaps.
4. Fix cycle: what changed, who approved, what was verified.
5. Before/after: score movement, caveats, and open risks.
6. Quote: omitted unless exact wording and attribution are approved in writing.

## Cadence

Publish one case-study candidate per quarter. If no client approval exists, publish an anonymized learning note instead of inventing specificity.
