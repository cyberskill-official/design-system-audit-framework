# TASK-GOV-003 - Quarterly RFC Cycle

**Repo-verifiable state:** RFC cadence and template ready.

## Cadence

- Week 1: open RFC window.
- Week 2: triage proposals.
- Week 3: maintainer review.
- Week 4: decision log and merge.

Quarterly cycles are for criteria evolution, scoring changes, translations, certification rules, and vertical-pack changes. Editorial fixes can land outside the cycle.

## Roles

- Author: writes proposal using `templates/rfc-template.md`.
- Maintainer: reviews scope and compatibility.
- Co-maintainer: checks governance and community impact.
- Domain reviewer: optional specialist for accessibility, privacy, performance, or sector-specific rules.

## Decision States

- accepted
- accepted_with_changes
- deferred
- rejected
- superseded

Every decision gets a dated note in the RFC file and a link from the next release notes.
