## Contribution

1. Propose a token or component.
2. Cite the website evidence that motivated it.
3. Add accessibility and responsive-state evidence.
4. Review in design and code.
5. Release with no-silent-regression notes.

## Release Cadence

- Weekly during extraction.
- Monthly after first system baseline.

## No-Silent-Regression Rule

Any change that weakens a previously accepted token, component, accessibility guarantee, or content rule must be tagged, explained, and approved before release.
