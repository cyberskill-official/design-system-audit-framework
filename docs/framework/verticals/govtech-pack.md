# FR-VERT-001 - Govtech Vertical Pack

**Repo-verifiable state:** Govtech addendum ready; named EU public-sector buyer remains external.

## Why Govtech First

Govtech is the only vertical pack that clearly strengthens DSAF's credibility instead of diluting it. Public-sector services have accessibility, transparency, consent, procurement, and trust requirements that map naturally to DSAF.

## Additional Evidence

| Area | Govtech evidence |
|---|---|
| Accessibility | WCAG conformance statements, assisted-digital support, keyboard and screen-reader evidence. |
| Service standard | Public service manual alignment or local equivalent. |
| Consent | Plain-language consent, data minimization, retention policy. |
| Procurement | Open standards, vendor exit, documented ownership. |
| Inclusion | Multilingual and low-bandwidth support where relevant. |
