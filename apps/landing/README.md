# DSAF Landing Page & Mini-Audit Widget

The public-facing marketing site and lead-generation portal for the Design System Audit Framework.

## Features

- **Blazing Fast Vite + React Frontend**: Built for maximum SEO performance and speed without heavy runtime frameworks.
- **Vanilla CSS Glassmorphism**: Utilizes the custom CyberSkill design tokens to render beautiful dark/light mode interfaces without Tailwind.
- **The DSAF Effect (Interactive Demo)**: A live visual before/after component demonstrating exactly how DSAF improves accessibility and component structure.
- **Live Mini-Audit Widget**: A mock URL scanning widget designed to capture leads by simulating a lightning-fast audit of an external design system.
- **Data Visualization**: Pure CSS-based graph components rendering the empirical 30-case benchmark study.

## Setup & Running Locally

1. Install dependencies:
```bash
npm install
```

2. Run the Vite development server:
```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view the site.
