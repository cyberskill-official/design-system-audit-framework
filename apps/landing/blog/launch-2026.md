# We built DSAF because design-system audits kept becoming taste arguments

**Show HN discussion link: pending operator submission.**

Welcome to the 125-criterion toolkit that finally brings objectivity to design system evaluations. The geography headwind is real when distributing design knowledge, but we hope this framework helps everyone.

## What DSAF is

DSAF is an open-source framework hosted at github.com/cyberskill-official/design-system-audit-framework. It provides the DSAF-25 Core for quick evaluations and a full rubric for deep dives.

![Ladder](/assets/dsaf-l0-l5-ladder.svg)

## Why we built it

We built it to enforce the no-silent-regression rule.

![Radar](/assets/dsaf-radar.svg)

## What we got wrong first

Initially, we didn't require named endorsement quotes, but now we do. No quote appears until the exact wording and attribution are approved in writing.

## What we got right, I think

Self-audits are capped at L3 until independent verification exists. This ensures honesty.

## Who this is for

Disclosure: I run CyberSkill. This tool is for all maintainers.
